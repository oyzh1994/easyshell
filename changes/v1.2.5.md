### 问题修复
1. 修复 PostgreSQL 查询页执行 DDL/DML 未提交、关闭连接后被回滚的问题，改为自动提交语义并在执行结束后恢复连接自动提交状态。
2. 修复 PostgreSQL 新增/修改表外键时 `ON UPDATE` 策略未写入、回显变为 NO ACTION 的问题。
3. 修复 PostgreSQL 表设计器把表空间设置为 `pg_default` 后重新打开不回显的问题。
4. 修复表/视图/函数/过程/序列设计器中默认值等输入框 Ctrl+S/Cmd+S 无法触发保存的问题（含 PostgreSQL、MySQL、MariaDB、达梦、SQLite）。
