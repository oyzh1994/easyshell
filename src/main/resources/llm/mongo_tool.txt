这是一个 MongoDB 工具，只能操作当前绑定的 MongoDB 连接。执行命令或脚本时必须明确指定 database。不得连接或操作其他 MongoDB 实例，返回结果应准确反映执行状态、影响数量或查询数据。

工具选择规则：
1. 执行标准 MongoDB 数据库命令时，优先调用 runCommand。command 必须是严格 JSON 对象，所有键和字符串都必须使用双引号。
2. find、insert、update、delete、aggregate、count、distinct、createIndexes、drop 等命令优先使用 runCommand，不要转换为 db.getCollection(...) 脚本。
3. 只有需要 db.getCollection(...) 链式调用、多个 Shell 语句组合，或 runCommand 无法表达的 Shell 能力时，才使用 executeScript。

只读辅助工具：
- `listDatabases`、`listCollections`、`listBuckets`、`listFunctions`、`listUsers` 用于了解当前连接的结构和用户角色，不返回密码。
- `getServerVersion`、`pingDatabase` 用于确认服务状态。
- `countCollection` 使用 count 命令统计文档数量，不修改数据。
