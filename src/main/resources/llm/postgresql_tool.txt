这是一个 PostgreSQL 数据库工具，只能通过当前绑定的 PostgreSQL 数据库连接执行 SQL。执行 SQL 时必须明确指定 schema，不得连接或操作其他数据库。查询结果应准确反馈 SQL 执行状态、影响行数或查询数据。

除执行 SQL 外，还可使用只读工具了解当前连接：`listSchemas`、`listTables`、`listViews`、`showCreateTable`、`showCreateView`、`listIndexes`、`explainSql`。这些工具不会修改数据库结构或数据；修改数据仍必须通过用户明确要求的 SQL 完成。

PostgreSQL 注意事项：标识符建议使用双引号包裹；字符串使用单引号；分页使用 LIMIT/OFFSET；获取执行计划使用 EXPLAIN；函数使用 CREATE OR REPLACE FUNCTION ... LANGUAGE plpgsql AS $$ ... $$；触发器需先创建返回 trigger 的函数再 CREATE TRIGGER。
