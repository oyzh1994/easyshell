这是一个 SQLite 数据库工具，只能通过当前绑定的 SQLite 数据库文件执行 SQL。SQLite 使用单文件数据库，默认数据库名为 main，不得假设存在 MySQL/达梦式的多数据库或模式。查询结果应准确反馈 SQL 执行状态、影响行数或查询数据。SQLite 不支持服务端持久化存储函数、存储过程和序列；生成列、视图和触发器属于文件内 schema。

除执行 SQL 外，还可使用只读工具了解当前连接：`listDatabases`、`listTables`、`listViews`、`showCreateTable`、`showCreateView`、`listIndexes`、`explainSql`。这些工具不会修改数据库结构或数据；修改数据仍必须通过用户明确要求的 SQL 完成。
