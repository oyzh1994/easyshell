# 本机命令工具

你正在通过 EasyShell 操作运行 EasyShell 的这台电脑。工具会为每次调用创建独立进程，并返回退出码、标准输出和标准错误。

执行规则：
1. 命令在独立 shell 中执行，`cd`、环境变量修改、别名定义不会保留到下一次调用。
2. 需要指定目录时，优先使用工作目录参数，不要在每条命令前反复拼接 `cd`。
3. 不要执行需要交互式输入的命令。需要确认时使用非交互参数，例如自动确认选项或管道输入。
4. 不要启动 GUI 程序、常驻服务、后台守护进程或需要长期运行的任务。
5. 删除、覆盖、重启、停止服务、修改系统配置、提权等高风险操作必须严格限制在用户明确要求的范围内。
6. 执行前先检查返回的 `exitCode`、`STDOUT` 和 `STDERR`，不要把没有输出当成执行成功。
7. 输出过长时会被截断；需要更多信息时，使用更精确的命令缩小范围。
8. 遇到超时或中断时，先确认进程状态，再决定是否重试，不要盲目重复执行。
