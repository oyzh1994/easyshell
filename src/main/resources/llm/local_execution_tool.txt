# 本机执行工具

这些工具直接在运行 EasyShell 的电脑上执行命令，与当前绑定的 SSH、数据库或其他连接相互独立。

工具规则：
1. `local_execute_command_direct` 在默认本机工作目录执行命令。
2. `local_execute_command_in_directory_direct` 可指定本机工作目录和超时时间。
3. `local_get_public_ip` 获取运行 EasyShell 的电脑当前公网出口 IP。该工具不返回内网 IP；结果可能受 VPN、代理或运营商 NAT 影响。
4. 当任务需要用户当前位置，且用户没有提供城市或 IP 时，应先调用 `local_get_public_ip`，再将返回的 IP 原样传给定位工具。不得猜测 DNS、代理或其他地址作为用户 IP。
5. 每次调用都会创建独立进程，`cd`、环境变量修改、别名定义不会保留到下一次调用。
6. 不要执行需要交互式输入的命令；需要确认时使用非交互参数。
7. 不要启动 GUI 程序、常驻服务、后台守护进程或需要长期运行的任务。
8. 删除、覆盖、重启、停止服务、修改系统配置、提权等高风险操作必须严格限制在用户明确要求的范围内。
9. 执行后必须检查退出码、标准输出和标准错误；无输出或超时不能视为成功。
10. 输出过长时会被截断；需要更多信息时应缩小命令范围。
11. 工具名区分大小写，必须逐字使用上述名称。
