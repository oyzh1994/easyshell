# PostgreSQL Docker 环境

以下命令适用于本机已安装 Docker 的环境，镜像使用 PostgreSQL 官方镜像。示例端口避开默认 5432，方便同时启动多个版本。

## 1. 启动

### 最新版本

```bash
docker run -itd --name easyshell-pg \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres@2026 \
  -e POSTGRES_DB=postgres \
  -p 15432:5432 \
  postgres:latest
```

### PostgreSQL 16

```bash
docker run -itd --name easyshell-pg16 \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres@2026 \
  -e POSTGRES_DB=postgres \
  -p 15432:5432 \
  postgres:16
```

### PostgreSQL 15

```bash
docker run -itd --name easyshell-pg15 \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres@2026 \
  -e POSTGRES_DB=postgres \
  -p 25432:5432 \
  postgres:15
```

### PostgreSQL 14

```bash
docker run -itd --name easyshell-pg14 \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres@2026 \
  -e POSTGRES_DB=postgres \
  -p 35432:5432 \
  postgres:14
```

Apple Silicon（M1/M2/M3）机器一般可直接使用官方多架构镜像；如果拉取到仅 amd64 的镜像，可追加 `--platform linux/amd64`。

## 2. 带测试对象启动

在 `docker/postgresql` 目录执行：

```bash
docker run -itd --name easyshell-pg-demo \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres@2026 \
  -e POSTGRES_DB=postgres \
  -p 15432:5432 \
  -v "$(pwd)/init.sql:/docker-entrypoint-initdb.d/init.sql:ro" \
  postgres:16
```

说明：

- `init.sql` 只在容器数据目录首次初始化时执行；如果容器或数据卷已存在，需要删除容器/卷后重新创建，或手动执行该文件。
- 测试对象位于 `demo` 模式，包含表、视图、函数、过程、序列、触发器、索引、注释和示例数据。
- 如果你在 EasyShell 中手动执行 `init.sql`：推荐使用“运行 SQL 文件”功能（逐条提交）；在查询页执行时，当前版本按自动提交语义逐条执行，旧版本请在脚本末尾追加 `COMMIT;`，否则关闭连接时 PostgreSQL 会回滚未提交的 DDL/DML。

## 3. 开启 SSL

生成自签名证书（有效期 365 天）：

```bash
mkdir -p pgssl
cd pgssl
openssl req -new -x509 -days 365 -nodes -text \
  -out server.crt \
  -keyout server.key \
  -subj "/CN=localhost"
chmod 600 server.key
chmod 644 server.crt

# 官方镜像内以 postgres 用户（通常 uid/gid 999）运行
docker run --rm -v "$(pwd)":/certs alpine chown -R 999:999 /certs
```

启动：

```bash
docker run -itd --name easyshell-pg-ssl \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres@2026 \
  -e POSTGRES_DB=postgres \
  -p 15433:5432 \
  -v "$(pwd)/server.crt:/var/lib/postgresql/server.crt:ro" \
  -v "$(pwd)/server.key:/var/lib/postgresql/server.key:ro" \
  postgres:16 \
  -c ssl=on \
  -c ssl_cert_file=/var/lib/postgresql/server.crt \
  -c ssl_key_file=/var/lib/postgresql/server.key
```

easyshell 连接时勾选“启用 SSL”，客户端会使用 `sslmode=require`。生产环境请使用 CA 签发的正式证书，不要使用上面的自签名证书。

## 4. 连接

在 easyshell 中选择“添加连接 -> 数据库 -> PostgreSQL”，填写：

```text
主机：127.0.0.1
端口：15432
数据库：postgres
用户：postgres
密码：postgres@2026
```

说明：

- PostgreSQL 一个连接对应一个数据库；切换数据库需要修改连接配置或新建连接。
- 连接成功后，树根显示当前数据库下的模式（Schema），默认包含 `public`，带测试对象的容器还包含 `demo`。
- “数据库”字段是 PostgreSQL 必要差异，MySQL/达梦连接没有该字段。

## 5. 常用运维命令

```bash
# 查看日志
docker logs -f easyshell-pg

# 进入容器使用 psql
docker exec -it easyshell-pg psql -U postgres -d postgres

# 查看所有数据库
docker exec -it easyshell-pg psql -U postgres -d postgres -c "\l"

# 查看指定模式下的表
docker exec -it easyshell-pg psql -U postgres -d postgres -c "\dt demo.*"

# 停止/删除容器
docker stop easyshell-pg
docker rm -f easyshell-pg
```

## 6. 清理

```bash
docker rm -f easyshell-pg easyshell-pg16 easyshell-pg15 easyshell-pg14 easyshell-pg-demo easyshell-pg-ssl
```
