# Oracle Docker 环境

以下命令在 `docker/oracle` 目录执行。示例同时覆盖 Oracle 11g 兼容路径和 Oracle 23c 现代路径，初始化脚本会创建 `DEMO/Demo2026` 模式及表、视图、序列、过程、函数和触发器。

## 1. 启动 Oracle 23c

`gvenzl/oracle-free` 是多架构镜像，Apple Silicon 可原生运行。Oracle Free 的 PDB 服务名为 `FREEPDB1`。Docker 默认选择当前节点的原生架构；需要显式指定时，Apple Silicon 使用 `--platform linux/arm64`，x86_64 环境使用 `--platform linux/amd64`。

```bash
docker run -itd --name easyshell-oracle23 \
  -e ORACLE_PASSWORD=easyshell@2026 \
  -p 31521:1521 \
  -v "$(pwd)/init-23c.sql:/container-entrypoint-initdb.d/init-23c.sql:ro" \
  gvenzl/oracle-free:23-slim-faststart
```

也可以使用 Compose：

```bash
docker compose -f oracle-23c.yml up -d
```

等待数据库完成初始化并变为 healthy：

```bash
docker logs -f easyshell-oracle23
docker exec easyshell-oracle23 healthcheck.sh
```

## 2. 启动 Oracle 11g

`gvenzl/oracle-xe:11` 仅提供 amd64 镜像。Intel Mac、Windows 或 x86 Linux 可直接运行；Apple Silicon 需要 Docker Desktop/Colima 开启 amd64 模拟。Oracle XE 11g 是非 CDB，服务名和 SID 均为 `XE`。

```bash
docker run -itd --name easyshell-oracle11 \
  --platform linux/amd64 \
  -e ORACLE_PASSWORD=easyshell@2026 \
  -p 21521:1521 \
  -v "$(pwd)/init-11g.sql:/container-entrypoint-initdb.d/init-11g.sql:ro" \
  gvenzl/oracle-xe:11-slim-faststart
```

也可以使用 Compose：

```bash
docker compose -f oracle-11g.yml up -d
```

Apple Silicon 如果使用 Colima，可按镜像文档创建 x86_64 虚拟机后再执行上述命令：

```bash
colima start --arch x86_64 --cpu 4 --memory 8
```

Docker Desktop 若报 `exec format error`、`no matching manifest` 或容器立即退出，说明当前 Docker VM 无法执行 amd64 Oracle 11g；这不是 EasyShell JDBC 驱动问题。

## 3. EasyShell 连接

选择“添加连接 -> 数据库 -> Oracle”。

Oracle 23c：

```text
主机：127.0.0.1
端口：31521
Service Name：FREEPDB1
用户：DEMO
密码：Demo2026
```

Oracle 11g：

```text
主机：127.0.0.1
端口：21521
Service Name：XE
用户：DEMO
密码：Demo2026
```

Oracle 11g 的 `DEMO` 是用户/模式名，不是服务名。`init-11g.sql` 创建的业务账号是 `DEMO/Demo2026`；Compose 中的 `easyshell@2026` 是 `ORACLE_PASSWORD`，即 `SYSTEM/SYS` 管理员密码。若连接管理账号，请使用 `SYSTEM/easyshell@2026`，服务名仍为 `XE`。

常见 `ORA-12514` 表示“数据库/Service Name”填写错误。例如提示服务 `DEMO` 未注册时，应把该字段从 `DEMO` 改为 `XE`；也可以填写 `SID:XE`。

“数据库”字段兼容三种连接形式：

```text
FREEPDB1
SID:XE
(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=127.0.0.1)(PORT=31521))(CONNECT_DATA=(SERVICE_NAME=FREEPDB1)))
```

- 普通值按 Service Name 解析。
- `SID:名称` 按 SID 解析。
- 以 `(` 开头的值按完整 TNS 描述符解析，忽略左侧主机、端口及 SSL 设置。
- 勾选 SSL 后 Service Name/SID URL 使用 `tcps`；完整描述符请在 `PROTOCOL=TCPS` 中自行指定。
- 代理支持 HTTP、SOCKS4/SOCKS5，带账号密码时使用 EasyShell 本地认证隧道。

### 11g/12c+ 兼容策略

- 分页通过 JDBC `DatabaseMetaData` 判断服务器版本：11g 使用嵌套 `ROWNUM`，12c 及以上使用 `OFFSET/FETCH`；版本无法识别时按 11g 处理。
- 自动递增默认生成序列和 `BEFORE INSERT` 触发器，可在 11g 和 12c+ 共用；建表界面也可显式选择 12c+ 的 `IDENTITY`。
- 11g 和 Oracle 12.1 标识符最长 30 字符，EasyShell 统一压缩自动递增序列/触发器名称，确保各版本都可执行；12.2+ 虽支持 128 字符，也不依赖该能力。
- Oracle 12c 多租户环境应连接 PDB Service Name；Oracle 11g XE 直接连接 `XE`。
- Slim 镜像可能裁剪 `DBMS_METADATA` 所需的 XSL 样式表；EasyShell 会自动回退到 `ALL_*` 元数据生成对象定义，不影响对象浏览、数据导出和 SQL 执行。

## 4. 初始化测试对象

脚本通过 `/container-entrypoint-initdb.d` 仅在全新容器首次初始化时执行。`DEMO` 模式包括：

- `USERS`、`ORDERS` 表和示例数据。
- `V_USERS` 视图。
- `DEMO_SEQ` 显式序列。
- `ADD_USER` 过程、`USER_COUNT` 函数。
- 更新时间触发器。
- 11g 使用 `*_ID_SEQ` + `*_ID_TRG` 实现自增。
- 23c 使用 `GENERATED BY DEFAULT ON NULL AS IDENTITY` 实现自增。

如果数据卷或同名容器已经存在，必须先删除旧容器再启动，或手工执行对应脚本。

## 5. 验证

容器内 SQL*Plus 验证：

```bash
docker exec -i easyshell-oracle23 \
  sqlplus -s DEMO/Demo2026@//127.0.0.1:1521/FREEPDB1 <<'SQL'
SET HEADING OFF FEEDBACK OFF
SELECT ID || ':' || USERNAME FROM USERS ORDER BY ID;
SELECT USER_COUNT FROM DUAL;
SQL

docker exec -i easyshell-oracle11 \
  sqlplus -s DEMO/Demo2026@//127.0.0.1:1521/XE <<'SQL'
SET HEADING OFF FEEDBACK OFF
SELECT ID || ':' || USERNAME FROM USERS ORDER BY ID;
SELECT USER_COUNT FROM DUAL;
SQL
```

JDBC 集成测试默认跳过，启动上述容器后执行：

```bash
mvn -Dtest=OracleDockerIntegrationTest \
  -Doracle.docker.mode=23c \
  -Doracle.docker.url='jdbc:oracle:thin:@tcp://127.0.0.1:31521/FREEPDB1' \
  -Doracle.docker.user=DEMO \
  -Doracle.docker.password=Demo2026 \
  -Doracle.docker.system.password=easyshell@2026 \
  test

mvn -Dtest=OracleDockerIntegrationTest \
  -Doracle.docker.mode=11g \
  -Doracle.docker.url='jdbc:oracle:thin:@tcp://127.0.0.1:21521/XE' \
  -Doracle.docker.user=DEMO \
  -Doracle.docker.password=Demo2026 \
  -Doracle.docker.system.password=easyshell@2026 \
  test
```

测试覆盖 Service Name、SID、TNS 描述符连接，模式切换，对象元数据，CRUD/结果元数据，PL/SQL，以及 11g ROWNUM 和 23c OFFSET/FETCH 分页。

## 6. 常用运维命令

```bash
docker logs -f easyshell-oracle23
docker exec -it easyshell-oracle23 bash
docker restart easyshell-oracle23
docker stop easyshell-oracle11
```
