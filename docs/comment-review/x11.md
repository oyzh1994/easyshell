# easyshell X11 支持（x11 包）代码审查文档

> 范围：easyshell/src/main/java/cn/oyzh/easyshell/x11/，共 2 个 .java，全部存活。
> 说明：仅新增文档，未改动任何 `.java`。

## ShellX11Manager

- 职责：x11 管理器，负责在 Windows/macOS 上启动、停止 X Server 进程，并可通过关机钩子收尾（相关公开方法均已标记 `@Deprecated`，内建启动方案为空实现）。
- 字段：

| 字段 | 类型 | 含义 |
|---|---|---|
| x11Process | `Process`（static，`@Deprecated`） | 已启动的 X Server 进程句柄 |
| setting | `ShellSetting`（static final） | 全局程序设置，取 `ShellSettingStore.SETTING`，提供 x11 工作目录与二进制名 |

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `static synchronized void startXServer_built_in()` | 内建方式启动 x11 服务 | 空实现（尚未落地） |
| `static synchronized void startXServer()`（`@Deprecated`） | 启动 x11 服务入口 | `x11Process` 存活则返回；`setting.x11WorkDir()` 为 `null` 时告警返回；`OSUtil.isWindows()` → `startXServer_windows()`；`OSUtil.isMacOS()` → `startXServer_macos()` |
| `static void startXServer_windows()`（private，`@Deprecated`） | Windows 下启动 X Server | `ProcessUtil.isProcessRunning(setting.x11Binary())` 为真则返回；`ShellX11Util.findExist(workdir, x11Binary)` 找不到时 `MessageBox.warn(ShellI18nHelper.x11Tip1())` 返回；`ThreadUtil.start` 异步拼命令 `cmd.exe /c start <bin> -clipboard -ac -wgl -multiwindow -silent-dup-error -notrayicon`，`RuntimeUtil.exec(command, null, new File(workdir))` |
| `static void startXServer_macos()`（private，`@Deprecated`） | macOS 下启动 X Server | `ProcessUtil.isProcessRunning({"XQuartz"})` 为真则返回；`findExist` 找不到则提示返回；`ThreadUtil.start` 中 `new ProcessBuilder(bin).directory(new File(workdir)).start()` |
| `static synchronized void stopXServer()`（`@Deprecated`） | 停止 x11 服务 | `x11Process` 非空时取 `toHandle()`；Windows/Linux 用 `handle.destroy()`，否则 `ProcessUtil.killProcess("X11.bin")`；最后 `x11Process=null` |
| `static { ... }` | 静态初始化块 | `RuntimeUtil.addShutdownHook(new Thread(ShellX11Manager::stopXServer))` 注册关机钩子 |

- 调用链：`startXServer → startXServer_windows / startXServer_macos → ShellX11Util.findExist → RuntimeUtil.exec / ProcessBuilder.start`；`JVM 退出 → shutdown hook → stopXServer`

## ShellX11Util

- 职责：x11 工具类，在工作目录中查找实际存在的 x11 二进制命令（方法均标记 `@Deprecated`）。
- 字段：无字段（仅静态方法）。
- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `static String findExist(String workdir, String[] x11Binary)` | 查找存在的 x11 二进制命令 | 委托 `findExist(workdir, "/", x11Binary)` |
| `static String findExist(String workdir, String midDir, String[] x11Binary)` | 带中间目录的查找 | 遍历 `x11Binary`，`FileUtil.exists(workdir + midDir + bin)` 命中即返回该 `bin`；全部不存在返回 `null` |

- 调用链：`ShellX11Manager.startXServer_windows / startXServer_macos → ShellX11Util.findExist → FileUtil.exists`
