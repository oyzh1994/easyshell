# easyshell S3 对象存储（s3 包）代码审查文档

> 说明：仅新增文档，未改动任何 `.java`。
> 范围：easyshell/src/main/java/cn/oyzh/easyshell/s3/，共 6 个 .java，全部存活。

本包基于 AWS SDK v2 实现 S3 兼容对象存储客户端，支持阿里云、腾讯云 COS、华为云 OBS 等，涵盖桶管理（版本控制/对象锁定/保留策略）、对象读写、目录删除、预签名 URL，以及路径解析与校验和拦截器。

---

## ShellS3Bucket

- 职责：S3 桶模型，实现 `ObjectCopier<ShellS3Bucket>`，承载桶的属性与保留策略。

- 字段：

| 字段 | 类型 | 含义 |
|---|---|---|
| name | `String` | 名称 |
| region | `String` | 区域 |
| creationDate | `String` | 创建时间 |
| versioning | `boolean` | 版本控制 |
| objectLock | `boolean` | 对象锁定 |
| retention | `boolean` | 是否开启保留 |
| retentionMode | `int` | 保留模式，0 compliance / 1 governance |
| retentionValidity | `int` | 保留有效期 |
| retentionValidityType | `int` | 保留有效期类型，0 day / 1 year |

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `getName()` / `setName(String)` | 名称读写 | 直接赋值 |
| `getRegion()` / `setRegion(String)` | 区域读写 | 直接赋值 |
| `getCreationDate()` / `setCreationDate(String)` | 创建时间读写 | 直接赋值 |
| `setCreationDate(Instant creationDate)` | 设置创建时间 | `Instant` 转 `Date` 后 `DateHelper.formatDateTimeSimple` |
| `isVersioning()` / `setVersioning(boolean)` | 版本控制读写 | 直接赋值 |
| `getVersioningStatus()` | 版本控制状态文案 | `versioning ? I18nHelper.enable() : I18nHelper.disable()` |
| `isObjectLock()` / `setObjectLock(boolean)` | 对象锁定读写 | 直接赋值 |
| `getObjectLockStatus()` | 对象锁定状态文案 | 同上 enable/disable |
| `isRetention()` / `setRetention(boolean)` | 是否保留读写 | 直接赋值 |
| `getRetentionStatus()` | 保留状态文案 | 同上 enable/disable |
| `getRetentionMode()` / `setRetentionMode(int)` | 保留模式读写 | 直接赋值 |
| `getRetentionValidity()` / `setRetentionValidity(int)` | 保留有效期读写 | 直接赋值 |
| `getRetentionValidityType()` / `setRetentionValidityType(int)` | 有效期类型读写 | 直接赋值 |
| `setRetention(DefaultRetention retention)` | 设置保留策略 | null 时 retention=false；否则按 `mode()==COMPLIANCE` 定 0/1，`days()` 为空取 years(type=1) 否则 days(type=0) |
| `copy(ShellS3Bucket bucket)` | 拷贝 | 字符串字段非空才覆盖，其余字段直接复制 |

- 调用链：`ShellS3Client.listBuckets → setRetention/getBucketRetention → ShellS3Bucket.copy`

## ShellS3Client

- 职责：S3 协议文件客户端，实现 `ShellFileClient<ShellS3File>`，封装桶管理与对象读写。

- 字段：

| 字段 | 类型 | 含义 |
|---|---|---|
| s3Client | `S3Client` | s3客户端 |
| connect | `ShellConnect` | 连接（final） |
| state | `SimpleObjectProperty<ShellConnState>` | 连接状态（final） |
| stateListener | `ChangeListener<ShellConnState>` | 当前状态监听器（final） |
| credentialsProvider | `StaticCredentialsProvider` | 签名提供者 |
| bucketInRegionCache | `Map<String,Boolean>` | 桶是否在某区域的缓存（final，`ConcurrentHashMap`） |
| appId | `String` | 应用id（腾讯 COS 需要） |
| deleteCompetitor | `Competitor` | 删除竞争器，并发度 5（final） |
| deleteTasks | `ObservableList<ShellFileDeleteTask>` | 删除任务列表（final） |
| uploadTasks | `ObservableList<ShellFileUploadTask>` | 上传任务列表（final） |
| downloadTasks | `ObservableList<ShellFileDownloadTask>` | 下载任务列表（final） |
| transportTasks | `ObservableList<ShellFileTransportTask>` | 传输任务列表（final） |
| uploadCompetitor | `Competitor` | 上传竞争器，并发度 2（final） |
| downloadCompetitor | `Competitor` | 下载竞争器，并发度 2（final） |
| transportCompetitor | `Competitor` | 传输竞争器，并发度 2（final） |

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `ShellS3Client(ShellConnect connect)` | 构造客户端 | 保存 connect，设置状态并 `addStateListener` |
| `region()` | 获取区域 | connect 的 region 为空则 `ShellS3Util.parseRegion(host)`，`ShellS3Util.ofRegion` |
| `initClient()` | 初始化客户端 | 由 user/password 建凭证；按 `isEnableProxy()` 构建 `UrlConnectionHttpClient`（`ShellProxyUtil.initProxy2`）；阿里云走 pathStyleAccess/chunkedEncoding 关闭；设置校验和系统属性并挂载 `ShellS3MD5Interceptor`；构建 `S3Client` |
| `start(int timeout)` | 启动 | `initClient` → 置 `CONNECTING` → `listBuckets()` 探测 → `CONNECTED` → `ShellClientChecker.push`；失败置 `FAILED`；`finally` `SystemUtil.gc()` |
| `getShellConnect()` | 获取连接 | 返回 connect |
| `isConnected()` | 是否已连接 | `s3Client != null` 且 `listBuckets()` 不抛异常 |
| `stateProperty()` | 状态属性 | 返回 state |
| `close()` | 关闭 | 关闭并置空 s3Client，置 `CLOSED` 并移除监听器 |
| `lsFileDynamic(String filePath, Consumer<ShellS3File> fileCallback)` | 动态列举 | 根路径列举桶（含区域判断）；否则 `ShellS3Path` 解析后 `listObjects` 输出对象与 `commonPrefixes` |
| `delete(String file)` | 删除文件 | 版本控制开启时 `deleteAllVersions`，再 `deleteNormalFile` |
| `deleteDir(String dir)` | 删除目录 | 版本控制开启时 `deleteAllVersionsInDirectory`，否则 `deleteNonVersionedDirectory` |
| `deleteDirRecursive(String dir)` | 递归删除目录 | 转调 `deleteDir` |
| `rename(ShellS3File file, String newName)` | 重命名 | 计算新路径 → `copyObject` → `deleteObject` |
| `exist(String filePath)` | 是否存在 | 根路径返回 true；对象用 `headObject`（目录直接 true），桶用 `headBucket` |
| `realpath(String filePath)` | 绝对路径 | 抛 `UnsupportedOperationException` |
| `touch(String filePath)` | 创建空对象 | `putObject(..., RequestBody.empty())` |
| `createDir(String filePath)` | 创建目录 | 抛 `UnsupportedOperationException` |
| `createDirRecursive(String filePath)` | 递归创建目录 | 抛 `UnsupportedOperationException` |
| `workDir()` | 工作目录 | 抛 `UnsupportedOperationException` |
| `cd(String filePath)` | 切换目录 | 抛 `UnsupportedOperationException` |
| `get(ShellS3File remoteFile, String localFile, Function<Long,Boolean> callback)` | 下载 | `getObject` + `ResponseTransformer.toOutputStream`，回调时包 `ShellFileProgressMonitor` |
| `getStream(ShellS3File remoteFile, Function<Long,Boolean> callback)` | 获取输入流 | 先 `getObject` 到临时文件，再 `FileInputStream`，回调时包 `ShellFileProgressMonitor` |
| `put(InputStream localFile, String remoteFile, Function<Long,Boolean> callback)` | 上传 | 回调时包 `ShellFileProgressMonitor`，`putObject` + `RequestBody.fromInputStream` |
| `putStream(String remoteFile, Function<Long,Boolean> callback)` | 获取输出流 | 抛 `UnsupportedOperationException` |
| `deleteCompetitor()` / `deleteTasks()` | 删除竞争器/任务 | 返回对应字段 |
| `uploadCompetitor()` / `uploadTasks()` | 上传竞争器/任务 | 返回对应字段 |
| `downloadCompetitor()` / `downloadTasks()` | 下载竞争器/任务 | 返回对应字段 |
| `transportCompetitor()` / `transportTasks()` | 传输竞争器/任务 | 返回对应字段 |
| `closeDelayResources()` | 关闭延迟资源 | 空实现 |
| `chmod(int permissions, String filePath)` | 权限变更 | 抛 `UnsupportedOperationException` |
| `fileInfo(String filePath)` | 文件信息 | 对象按前缀 `listObjects` 匹配文件/目录，桶返回 `new ShellS3File(getBucket(bucketName))` |
| `isCdSupport()` / `isChmodSupport()` / `isRealpathSupport()` / `isWorkDirSupport()` | 能力查询 | 均 false |
| `isPutStreamSupport()` / `isCreateDirSupport()` / `isCreateDirRecursiveSupport()` | 能力查询 | 均 false |
| `listBuckets()` | 列举桶 | 遍历桶，`fillAppId`、区域判断、装配 `ShellS3Bucket`（含 retention/versioning/objectLock） |
| `isBucketInCurrentRegion(String bucketName)` | 私有：桶是否在当前区域 | 先查缓存，`headBucket` 取区域与 `this.region()` 比较；403 静默，其余打印 |
| `getBucket(String bucketName)` | 获取桶 | 遍历 `listBuckets` 匹配名 |
| `getAppId()` | 私有：获取appId | 懒加载 `ShellS3Util.getAppId(user, password)` |
| `fillAppId(String bucketName)` | 私有：填充appId | 腾讯 COS 且未填充时，取桶名最后 `-` 后段 |
| `createBucket(ShellS3Bucket bucket)` | 创建桶 | 腾讯拼接 appId；`createBucket` 后按需设置版本控制与保留策略 |
| `updateBucket(ShellS3Bucket bucket)` | 修改桶 | 设置版本控制，按需设置保留策略 |
| `deleteBucket(ShellS3Bucket bucket, boolean force)` | 删除桶 | force 时按版本控制清空对象，再 `deleteBucket` |
| `isBucketVersioning(String bucketName)` | 是否启用版本控制 | `getBucketVersioning` 后 `"Enabled".equals(statusAsString())` |
| `setBucketVersioning(String bucketName, boolean enable)` | 设置版本控制 | 状态相同则跳过，否则 `putBucketVersioning`（Enabled/Suspended） |
| `isBucketObjectLock(String bucketName)` | 是否启用对象锁定 | `getObjectLockConfiguration`，忽略 403 与未启用类异常 |
| `enableBucketObjectLocking(String bucketName)` | 开启对象锁定 | `putObjectLockConfiguration`（Enabled） |
| `setBucketRetentionByDays(String bucketName, int days, ObjectLockRetentionMode mode)` | 按天保留 | `ObjectLockConfiguration` + `DefaultRetention.days` |
| `setBucketRetentionByYears(String bucketName, int years, ObjectLockRetentionMode mode)` | 按年保留 | `ObjectLockConfiguration` + `DefaultRetention.years` |
| `getBucketRetention(String bucketName)` | 获取默认保留规则 | `getObjectLockConfiguration`，无规则返回 null |
| `generatePresignedUrl(String bucketName, String key, Duration duration)` | 生成预签名URL | `S3Presigner` 构建 `GetObjectPresignRequest` 后 `presignGetObject` |

- 调用链：`start → initClient → ShellS3MD5Interceptor / S3Client.builder → listBuckets`；`delete → ShellS3Util.deleteAllVersions/deleteNormalFile`；`deleteDir → ShellS3Util.deleteAllVersionsInDirectory/deleteNonVersionedDirectory`；`listBuckets → getBucketRetention/isBucketVersioning/isBucketObjectLock → fillAppId/isBucketInCurrentRegion`

## ShellS3File

- 职责：S3 文件模型，实现 `ShellFile`，适配 `S3Object`/`CommonPrefix`/`Bucket`/`ShellS3Path` 多种来源。

- 字段：

| 字段 | 类型 | 含义 |
|---|---|---|
| fileName | `String` | 文件名称 |
| parentPath | `String` | 父路径 |
| bucket | `Bucket` | 桶 |
| s3Object | `S3Object` | 文件对象 |
| prefix | `CommonPrefix` | 文件前缀 |
| bucketName | `String` | 桶名称 |
| lastModified | `Instant` | 最后修改时间 |
| fileSize | `Long` | 文件大小 |

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `ShellS3File(S3Object s3Object, String bucket)` | 构造（对象） | 按 key 最后 `/` 拆分文件名与父路径 |
| `ShellS3File(CommonPrefix prefix, String bucket)` | 构造（前缀） | 去尾 `/`，`ShellFileUtil.name/parent` |
| `ShellS3File(Bucket bucket)` | 构造（桶） | fileName=bucket.name，parentPath="/" |
| `ShellS3File(ShellS3Path s3Path, Instant lastModified, Long fileSize)` | 构造（路径） | 从 `ShellS3Path` 取 fileName/bucketName/parentPath |
| `isFile()` | 是否文件 | s3Object 非空且 key 不以 `/` 结尾 |
| `isLink()` | 是否链接 | 恒 false |
| `getOwner()` / `getGroup()` | 属主/属组 | 返回 `"-"` |
| `getFileSize()` | 大小 | fileSize 优先，否则 `s3Object.size()`，兜底 0 |
| `setFileSize(long fileSize)` | 设置大小 | 赋值 |
| `getFileName()` / `setFileName(String)` | 文件名读写 | 直接赋值 |
| `isDirectory()` | 是否目录 | bucket/prefix 非空即目录，或 s3Object key 以 `/` 结尾 |
| `getParentPath()` | 父路径 | 返回 parentPath |
| `getPermissions()` / `setPermissions(String)` | 权限读写 | 返回 `"-"` / 空实现 |
| `getModifyTime()` | 修改时间 | lastModified 优先，否则 `s3Object.lastModified()`，`DateHelper.formatDateTime` |
| `setModifyTime(String modifyTime)` | 设置修改时间 | 解析后转 `Instant` |
| `copy(ShellFile t1)` | 拷贝 | 从 `ShellS3File` 复制 prefix/bucket/s3Object/bucketName/lastModified/fileSize/fileName/parentPath |
| `getFilePath()` | 文件路径 | 桶返回默认路径；否则拼 `/`+bucketName+parentPath+fileName |
| `getFileKey()` | 文件key | `ShellS3Util.parseFileKey(super.getFilePath())` |
| `getBucketName()` / `setBucketName(String)` | 桶名读写 | 直接赋值 |
| `destroy()` | 销毁 | 各字段置 null |

- 调用链：`ShellS3Client.lsFileDynamic → new ShellS3File(S3Object/CommonPrefix/Bucket)`；`get/getStream → getFileKey → ShellS3Util.parseFileKey`

## ShellS3MD5Interceptor

- 职责：S3 执行拦截器，为需要 MD5 校验和的请求（部分阿里云、腾讯云场景）自动补 `Content-MD5` 头。

- 字段：无字段

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `modifyHttpRequest(Context.ModifyHttpRequest context, ExecutionAttributes executionAttributes)` | 修改请求 | 非必需或已含 MD5 直接返回；异步体会抛 `IllegalStateException`；同步体用 `Md5Utils.md5AsBase64` 计算并 `putHeader(Header.CONTENT_MD5, ...)` |
| `isHttpChecksumRequired(ExecutionAttributes executionAttributes)` | 私有：是否需要http校验和 | `HTTP_CHECKSUM_REQUIRED` 非空或 `isMd5ChecksumRequired` |
| `isMd5ChecksumRequired(ExecutionAttributes executionAttributes)` | 是否需要md5校验和 | `getResolvedChecksumSpecs` 算法为空且 `isRequestChecksumRequired` |
| `getResolvedChecksumSpecs(ExecutionAttributes executionAttributes)` | 获取已解析校验和规范 | 取 `RESOLVED_CHECKSUM_SPECS`，为空则 `resolveChecksumSpecs` |
| `resolveChecksumSpecs(ExecutionAttributes executionAttributes)` | 解析校验和规范 | 从 `HTTP_CHECKSUM` 构建 `ChecksumSpecs` |

- 调用链：`S3Client.builder().addExecutionInterceptor → modifyHttpRequest → isHttpChecksumRequired → isMd5ChecksumRequired → resolveChecksumSpecs`

## ShellS3Path

- 职责：S3 路径解析，格式 `/桶/路径`，提供文件路径、前缀、桶名、父路径等派生值。

- 字段：

| 字段 | 类型 | 含义 |
|---|---|---|
| path | `String` | 文件路径（final） |

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `ShellS3Path(String path)` | 构造s3路径 | 空串转 `/`，补前导 `/`，去尾部 `/` |
| `filePath()` | 获取文件路径 | 取首个 `/` 之后的子串，无则 `/` |
| `prefix()` | 获取前缀 | `ShellS3Util.toPrefix(filePath())` |
| `fileName()` | 获取文件名 | 最后一个 `/` 之后的子串 |
| `bucketName()` | 获取桶名称 | 首个 `/` 与第二个 `/` 之间的子串 |
| `parentPath()` | 获取父目录 | 在 filePath 内取到最后一个 `/` 为止 |
| `of(String filePath)` | 创建s3路径 | `new ShellS3Path(filePath)` |

- 调用链：`ShellS3Client.delete/deleteDir/exist/touch/fileInfo → ShellS3Path.of → prefix/bucketName/filePath/parentPath → ShellS3Util.toPrefix`

## ShellS3Util

- 职责：S3 工具类，提供前缀转换、区域解析、文件 key 处理，以及多场景的桶/目录/对象删除。

- 字段：无字段

- 方法：

| 方法 | 说明 | 关键逻辑/调用 |
|---|---|---|
| `toPrefix(String fPath)` | 转换为s3前缀 | `/` 转空串，无尾 `/` 补 `/`，否则原样 |
| `deleteNonVersionedDirectory(S3Client s3Client, String bucketName, String directoryPath)` | 删除非版本控制桶中的目录 | `listObjectsV2` 分页 + `deleteObjects`（`bypassGovernanceRetention`），返回删除数 |
| `deleteAllVersionsInDirectory(S3Client s3Client, String bucketName, String directoryPath)` | 删除目录下所有版本 | `listObjectVersions` 分页，收集 versions 与 deleteMarkers，按 1000 分批删除 |
| `deleteNormalFile(S3Client s3Client, String bucketName, String objectKey)` | 删除普通文件 | `deleteObject`（`bypassGovernanceRetention`） |
| `deleteAllVersions(S3Client s3Client, String bucketName, String objectKey)` | 删除文件所有版本 | `listObjectVersions` 过滤精确 key，按 1000 分批删除 |
| `deleteVersionedBucketObjects(S3Client s3Client, String bucketName)` | 删除版本控制的桶对象 | `listObjectVersions` 分别删除 versions 与 deleteMarkers（未开启 bypass） |
| `deleteNonVersionedBucketObjects(S3Client s3Client, String bucketName)` | 删除无版本控制的桶对象 | `listObjectsV2` 分页 + `deleteObjects` |
| `ofRegion(String region)` | 创建Region | 空返回 `Region.US_EAST_1`，否则 `Region.of` |
| `parseRegion(String host)` | 解析区域 | 阿里云取首段 `://` 后；腾讯/华为取第二段 |
| `parseFileKey(String fKey)` | 解析文件key | 去前导 `/` |
| `getAppId(String secretId, String secretKey)` | 获取腾迅appId | 手工构造 TC3-HMAC-SHA256 签名请求 `cam.tencentcloudapi.com` 的 `GetUserAppId`，从响应截取 AppId |

- 调用链：`ShellS3Client.delete → ShellS3Util.deleteAllVersions/deleteNormalFile`；`ShellS3Client.deleteDir → deleteAllVersionsInDirectory/deleteNonVersionedDirectory`；`ShellS3Client.deleteBucket → deleteVersionedBucketObjects/deleteNonVersionedBucketObjects`；`region → parseRegion → ofRegion`；`ShellS3File.getFileKey → parseFileKey`
