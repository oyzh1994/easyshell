# H2 数据库管理功能需求与设计

## 1. 文档目的

本文档定义 EasyShell H2 数据库管理功能的范围、架构、接口、异常策略、测试与验收标准。设计以现有 SQLite 实现为主要参照（同为嵌入式数据库、单连接单库、树结构不设独立数据库动作节点），并参考 MySQL、MariaDB、达梦实现中的标准 SQL 数据库模式（schema、INFORMATION_SCHEMA、标准事务），不复制服务端数据库的多库、存储过程、事件和调度器能力。

## 2. 目标用户

- 需要在本机创建、打开和维护 H2 文件数据库的开发与测试人员。
- 需要连接远程 H2 TCP 服务器（`h2:tcp`）浏览和管理数据库的用户。
- 需要使用 H2 内存库做快速原型验证，并通过统一 JavaFX 客户端管理 H2、SQLite、MySQL 和达梦连接的桌面用户。

## 3. 功能范围

### 3.1 本期范围

- H2 连接的新建、编辑、测试、打开和关闭。
- 三种连接模式支持：
  - 文件模式（`jdbc:h2:file:`）：本地 `.mv.db` 文件，支持路径选择、只读打开（`ACCESS_MODE_DATA=r`）与文件不存在时创建（H2 默认行为，取消勾选时校验文件必须存在）。
  - 内存模式（`jdbc:h2:mem:`）：私有内存库，库名可自定义，支持 `DB_CLOSE_DELAY=-1` 保持连接期间库不销毁。
  - 远程模式（`jdbc:h2:tcp://` 与 `jdbc:h2:ssl://`）：主机、端口、数据库名、用户名、密码。
- 用户名/密码支持（H2 默认允许空）。
- 数据库版本、产品名、文件路径/内存标识、大小、用户、默认 schema、只读状态、事务隔离级别、兼容模式等信息展示。
- 表和视图浏览，包含对象名称、类型、SQL 定义、字段名、类型、长度、非空、主键、默认值、自增（IDENTITY）和行数。
- SQL 编辑、格式化、多语句执行、查询结果展示、更新数量与耗时展示；多语句在单个 JDBC 事务中执行，成功提交、失败回滚。
- 表设计器支持字段、主键、非空、唯一、默认值、CHECK、自增（`GENERATED BY DEFAULT AS IDENTITY`）、生成列（`GENERATED ALWAYS AS`）与表级约束；H2 支持标准 `ALTER TABLE`，表更新使用 ALTER 序列而非 SQLite 式临时表重建；字段扩展属性（自增、生成列表达式、字段注释）独立编辑。
- 视图设计器与 SQLite/MySQL 一致，SQL 定义使用独立的 Definition 页签，Preview 页签单独展示生成 DDL；已有视图使用原名称保存，新视图首次保存时弹窗设置名称。
- 表数据支持分页、结构化条件过滤、新增、删除、应用、丢弃、导入和导出；新增行未填写的列可使用数据库默认值。H2 2.x 视图为只读对象，视图数据支持分页、过滤和导出，不提供行更新。
- 表/视图记录编辑支持单元格内 `Ctrl/Cmd+S` 触发应用保存。
- 表节点支持打开、设计、重命名、清空、删除、导出、dump、克隆和表信息；视图节点支持打开、设计、重命名、删除、克隆、导出和视图信息。H2 支持 `ALTER TABLE ... RENAME TO`，提供重命名；不提供 SQLite 特有的"重置自增"动作（H2 IDENTITY 由系统管理）。
- 索引与触发器通过 SQL 定义编辑（树节点展示索引/触发器元数据，设计入口为 SQL 编辑），与 SQLite 策略一致；CHECK 约束在设计器中结构化编辑。
- 数据工具支持 SQL/JSON/XML/CSV/HTML/XLS/XLSX/TXT 导出、SQL/JSON/XML/CSV/XLS/XLSX/TXT 导入、库或表 dump、SQL 文件执行，以及 H2 数据库之间的表/视图/数据传输（文件↔文件、文件↔内存、本地↔远程均可）。
- SQL 终端与 SQLite/MySQL 保持一致，支持 SQL 及 `show tables;`、`show schemas;`、`show databases;`、`use`、`help`、`clear`；`use` 接受 schema 名并执行 `SET SCHEMA`；其余输入直接按 SQL 执行。
- 连接状态、执行状态、SQL 错误、文件错误、只读错误和资源关闭失败提示。
- 连接引导、连接树、标签页、FXML 页面、国际化键（8 个语言文件）和 H2 驱动依赖集成。
- LLM 标签能力（`LLMTabCapability`）与 H2 专用 SQL/原始结果集工具。

### 3.2 明确不在本期范围

- H2 文件加密（`CIPHER=AES`）与密钥管理；用户仍可通过环境参数自行附加。
- 多 schema 可视化管理：第一期只管理当前默认 schema（默认 `PUBLIC`，可通过环境参数 `schema=` 指定）；用户可通过 `SET SCHEMA` SQL 使用其他 schema。
- 函数设计器：H2 的持久化函数为 Java 别名（`CREATE ALIAS`，指向 Java 方法或源码），无法用 SQL 表达式设计器表达；本期不提供函数设计器与函数分组节点，函数通过 SQL 终端/查询页执行 `CREATE ALIAS` 创建。
- H2 Web Console、TCP/PG 服务器启动管理、`CREATE LINKED TABLE` 可视化。
- 兼容模式（`MODE=MySQL` 等）的可视化切换；可通过环境参数 `mode=` 设置。
- 集群（`AUTO_SERVER` 之外的集群特性）与高级备份工具（`BACKUP`/`RESTORE` 命令可视化）。

## 4. 核心业务流程

1. 用户从连接引导选择 H2。
2. 用户选择连接模式：文件模式选择已有文件或指定新文件；内存模式输入库名；远程模式输入主机、端口、库名和凭据。
3. 控制器校验对应模式的输入：文件模式校验路径、父目录与创建策略；远程模式校验主机/端口/库名非空。连接名称为空时按库名兜底。
4. `ShellH2ConnConfig` 承载全部连接参数（继承 `DBConnConfig`），由 `ShellH2ConnManager` 构造 JDBC URL 并创建连接。
5. 连接成功后打开 `ShellH2Tab`，左侧加载表和视图，右侧提供查询与终端标签。
6. 双击表或视图打开分页数据标签，读取 `INFORMATION_SCHEMA` 元数据、过滤条件和行数并展示。
7. 查询标签通过 H2 SQL 解析器（`SqlDatabase.H2`）拆分语句；无显式事务时在单个 JDBC 事务中执行，成功提交、失败回滚，显式事务命令由 JDBC 事务边界适配。
8. 关闭标签或连接时释放结果集、语句、连接和状态监听器；内存库随最后连接关闭销毁，属预期行为并在连接信息中提示。
9. 从对象树或根菜单打开表或视图设计器，保存前生成 H2 DDL 预览；保存后刷新树和对象标签。
10. 从根菜单或表节点打开导入、导出、dump、SQL 文件执行或传输页面；后台任务支持进度、错误继续策略和中断。
11. 传输前校验源与目标连接不同，并按所选表/视图决定结构与数据迁移范围。

## 5. H2 能力边界

- 文件模式一个连接对应一个 H2 主文件；`host` 保存文件路径（不含 `.mv.db` 后缀，H2 驱动自动追加）；内存模式 `host` 保存库名；远程模式 `host` 保存主机名、`port` 保存端口、`database` 保存库名。
- H2 为标准 SQL 型数据库，强类型；UI 显示声明类型与实际 JDBC 值。
- 表结构以 `INFORMATION_SCHEMA.TABLES`、`INFORMATION_SCHEMA.COLUMNS`、`INFORMATION_SCHEMA.INDEXES`、`INFORMATION_SCHEMA.TABLE_CONSTRAINTS`、`INFORMATION_SCHEMA.KEY_COLUMN_USAGE`、`INFORMATION_SCHEMA.CHECK_CONSTRAINTS` 为准。
- 标识符默认大小写不敏感且未加引号时按大写存储；SQL 生成统一使用双引号引号化以保留用户输入的大小写。
- DDL 中 `CREATE TABLE` 可通过 `IF NOT EXISTS`；H2 表更新使用标准 `ALTER TABLE`（`ADD COLUMN`/`ALTER COLUMN`/`DROP COLUMN`/`RENAME TO` 等），无需临时表重建。
- H2 支持标准事务（READ COMMITTED 默认隔离级别）；DDL 在 H2 中自动提交，多语句批次中 DDL 语句不参与 JDBC 事务回滚，错误信息明确提示。
- 文件模式默认单进程独占；`AUTO_SERVER=TRUE`（环境参数可选）允许多进程混合访问。
- 只读模式使用 `ACCESS_MODE_DATA=r`；"文件不存在时创建"未勾选时目标文件必须存在，避免路径拼写错误静默创建空库。
- 兼容模式、自动服务器、`DB_CLOSE_DELAY`、锁超时等属于连接级设置，可由环境参数覆盖。

## 6. 数据结构

### 6.1 通用 `fx-db` 层

- `DBDialect.H2`：统一方言标识（新增）。
- `DBBaseSqlParser`：使用 `SqlDatabase.H2`（base-common 已存在）进行拆分、格式化、查询识别和注释处理。
- `DBUtil` / `DBDataUtil`：H2 标识符使用双引号并转义内部双引号，字符串使用单引号并转义内部单引号。
- `DBConnConfig`、`DBConnManager`、`DBClient`、`DBQueryResult`：继续复用现有连接、执行和结果抽象。

### 6.2 EasyShell H2 层

- `ShellH2ConnConfig`：继承 `DBConnConfig`，保存连接模式（FILE/MEM/REMOTE）、只读、按需创建、默认 schema、兼容模式、AUTO_SERVER、DB_CLOSE_DELAY 等参数。
- `H2DatabaseFileField`：EasyShell H2 专用文件路径选择组件（文件模式，扩展名不限，展示 `.mv.db` 提示）。
- `H2Table`：名称、注释、SQL 定义、对象类型、约束、字段。
- `H2View`：名称、注释、定义。
- `H2Column`：名称、类型、长度/精度、非空、主键、默认值、自增（identity）、生成列、注释。
- `H2ExecuteResult`：SQL、列、只读行、更新数量、耗时、成功状态和错误消息。
- `H2Database`：名称、版本、产品名、路径/内存标识、大小（文件模式）、用户、schema、只读状态、隔离级别。
- `H2SchemaObject`：`INFORMATION_SCHEMA` 通用对象模型（表/视图/索引/触发器元数据）。
- `H2SqlGenerator`：表、视图、索引、触发器和 INSERT 字面量生成。
- `H2SchemaManager`：创建表/视图、ALTER 序列表更新、重命名、克隆。
- `data.h2.*`：导出/导入 DTO、文件 writer、SQL/CSV/JSON 转换和 dump/import/export/run-file/transport 处理器。

## 8. 接口设计

### 8.1 `ShellH2Client`

- `start(int timeout)`：按连接模式构造 URL 并打开连接，更新 `ShellConnState`。
- `close()`：幂等关闭连接管理器和监听器。
- `isConnected()`：校验 JDBC 连接有效性。
- `selectTables()` / `selectViews()`：从 `INFORMATION_SCHEMA` 读取当前 schema 的用户对象（排除 `INFORMATION_SCHEMA` 自身对象）。
- `selectColumns(tableName)`：读取列定义（类型、长度、非空、主键、默认值、自增、生成列、注释）。
- `selectRecords(..., filter)` / `selectRowCount(tableName, filter)`：分页查询和计数中应用 WHERE 过滤条件。
- `database()`：读取版本、产品名、路径/内存标识、大小、用户、schema、只读状态和隔离级别。
- `executeSql(String sql)`：返回 `DBQueryResults<H2ExecuteResult>`，事务策略与 SQLite 一致。
- `executeSqlRaw(...)`：提供 JDBC 原始结果并保证事务与资源恢复。
- `explainSql(String)`：使用 `EXPLAIN ANALYZE`（H2 支持）或 `EXPLAIN PLAN FOR` 包装。
- `selectSchemaObjects(...)`：读取表、视图、索引、触发器元数据。
- `renameTable/clearTable/truncateTable/dropTable/cloneTable`：表重命名（`ALTER TABLE ... RENAME TO`）、清空（`TRUNCATE TABLE`）、删除和结构/数据克隆。
- `renameView/dropView/cloneView`：视图重命名、删除和克隆。

### 8.2 连接配置映射

- `ShellConnect.type = ShellPrototype.H2`
- 文件模式：`ShellConnect.host` = H2 文件绝对路径（规范化，不含 `.mv.db`）
- 内存模式：`ShellConnect.host` = 内存库名；远程模式：`host`/`port`/`database` = 主机/端口/库名
- `ShellConnect.user/password` = H2 用户名/密码（允许为空）
- `ShellConnect.environment` = JDBC 键值，每行 `key=value`：`urlMode`、`schema`、`mode`（兼容模式）、`autoServer`、`dbCloseDelay`、`accessModeData`、`createIfMissing` 等
- `ShellConnect.connectTimeOut` = 连接超时秒数

### 8.3 JDBC URL 构造规则

- 文件模式：`jdbc:h2:file:<路径>[;ACCESS_MODE_DATA=r|rw][;AUTO_SERVER=TRUE][;IFEXISTS=TRUE|FALSE]`
- 内存模式：`jdbc:h2:mem:<库名>[;DB_CLOSE_DELAY=-1]`
- 远程模式：`jdbc:h2:tcp://<host>:<port>/<库名>`（SSL 为 `jdbc:h2:ssl://`）
- 兼容模式与自定义属性按环境参数追加为 URL 属性。

## 9. UI 交互

- 连接窗口提供名称、连接模式单选（文件/内存/远程）、对应模式字段（文件路径 + 只读 + 创建策略；内存库名 + DB_CLOSE_DELAY；主机/端口/库名/用户名/密码）、默认 schema、环境参数、备注与测试连接。
- 文件模式使用 H2 专用控件（`H2DatabaseFileField`），实际数据库主文件必须为 `*.mv.db`；非标准后缀会在提交连接前给出明确错误，不会静默生成重复后缀文件。
- H2 单库场景树根节点表示当前数据库（文件名/库名），其下直接展示表、视图、查询和终端分组，不设数据库动作节点与函数分组；树结构与 SQLite 完全对齐。
- 连接打开后，表、视图和查询分组节点显示各自数量；双击按需加载子节点；新增表、视图或查询时增量插入对应分组并更新数量。
- 对象标签展示字段表与数据表，工具栏支持刷新。
- 查询标签支持保存查询、格式化、执行、快捷键、多结果集与 Explain 操作（`EXPLAIN PLAN FOR`）。
- 终端使用当前库名和连接状态作为提示符，基础命令由终端处理器直接查询当前连接的表/schema 信息，其余输入按 SQL 执行。
- 根节点菜单提供新建表、新建视图、导入、导出、dump、运行 SQL 文件和传输；表节点提供设计、表信息、导出和 dump，视图节点提供设计和视图信息。
- 查询分组支持新建、打开已保存查询、重命名、删除和刷新；查询变更事件同步树节点与已打开标签。
- 表设计采用 MySQL/SQLite 同款字段网格：名称、类型（H2 类型下拉）、长度/精度、主键、非空、唯一、默认值，字段扩展属性（自增、生成列、注释）独立子页；索引与触发器使用 SQL 定义编辑；CHECK 约束结构化编辑。
- 表数据使用独立分页标签，支持结构化过滤、新增、删除、应用、丢弃、刷新、导入、导出和分页；视图数据共享查询和展示能力，但保持只读，避免生成 H2 不支持的视图 DML。
- H2 视图没有主键约束；对简单单表投影视图根据源表主键和列别名推断主键角色，JOIN、聚合和过滤视图不推断。推断结果只用于展示，不会把 H2 视图变成可更新对象。
- 记录单元格复用 `DBNodeUtil.getNodeBackground` 类型着色；NULL 提示、显式 NULL/空串菜单、默认值插入与 SQLite 一致。
- 数据网格中 BLOB（`VARBINARY`）按十六进制展示，只读保护与 SQLite 一致。
- 设计器保存前显示 SQL 预览，未保存标签关闭时要求确认。
- 导出、导入、dump、SQL 文件和传输窗口统一为 MySQL 风格分步向导；传输窗口按源连接、目标连接、数据选项、表和视图选择、执行消息分步展示。
- 数据页面将 JDBC/文件 I/O 放入后台线程，提供开始、停止、状态、消息、批量进度和出错后继续选项。
- 页面工厂支持普通导出、预配置查询导出、数据库/表 dump 和由连接配置临时创建源/目标客户端的传输入口。
- H2 连接标签实现 LLM 标签能力，提供 SQL 执行和原始 JDBC 结果集工具。
- 非 UI 线程只执行 JDBC；JavaFX 控件更新统一回到 FX 线程。

## 10. 异常与资源管理

- 文件模式：文件路径为空、父目录不可写、文件存在但不是 H2 文件分别显示明确错误；未勾选创建且文件不存在时直接报错，不静默创建。
- 远程模式：主机不可达、端口错误、认证失败返回带主机信息的可读错误。
- 内存模式：库名为空校验；连接关闭后内存库销毁，重开连接会得到空库，此行为在连接信息中明确提示。
- 只读连接上的写 SQL 由 H2 返回错误，并保留语句上下文。
- SQL 批次任一语句失败时回滚整个批次（DDL 自动提交语句除外，错误信息单独提示），并在结果对象中记录失败语句。
- `Connection`、`Statement`、`ResultSet` 使用 try-with-resources 或 `IOUtil.close` 成对释放。
- 关闭流程幂等，状态监听器移除后不重复发送关闭事件。
- UI 任务捕获 `Throwable`，显示错误但不得使 JavaFX Application Thread 崩溃。
- dump、导入、导出、SQL 文件和传输处理器保证 writer/reader/语句/结果集关闭；中断路径不继续写入。
- 传输源连接与目标连接相同、表不存在、列不兼容和只读目标均返回明确错误。

## 11. 兼容性策略

- 使用 `com.h2database:h2` 官方驱动（纯 Java，无原生库需求，全平台一致）。
- JDBC URL 按第 8.3 节规则构造；用户输入不直接拼接进 SQL 值。
- SQL 解析使用 `SqlDatabase.H2`；支持字符串/注释中的分号；无法解析时回退到原始语句。
- 标识符双引号转义与 SQLite/Dameng 一致；未引号化标识符按 H2 大写规则存储，元数据查询统一大写匹配。
- 旧连接数据无需迁移；未知类型继续按现有默认 SSH 行为处理。
- Java 版本沿用工程 Java 25，FXML、国际化和 Maven 配置不引入额外 UI 框架。
- H2 2.x 的 `INFORMATION_SCHEMA` 布局为准（1.4.x 旧版不做兼容承诺）。

## 12. 测试范围

- `fx-db`：H2 方言映射、标识符与字符串转义、SQL 拆分/查询识别、连接配置归一化与 URL 构造。
- EasyShell：连接类型分派、三种模式连接生命周期、文件创建/打开/只读、内存库生命周期、远程 URL 构造。
- 元数据：表/视图/字段/行数/数据库信息、保留字对象名、引号名称、大小写混合名称。
- SQL：DDL、DML、多语句提交、失败回滚、更新数量、结果集、空结果、错误语句、显式事务。
- H2 特性：IDENTITY 自增列、生成列、CHECK 约束、复合主键、注释、`TRUNCATE`、`ALTER TABLE RENAME`。
- 边界：路径为空、文件丢失、非 H2 文件、空数据库、中文数据、VARBINARY、NULL、内存库销毁重建。
- UI 架构：FXML 可加载、入口路由、树节点与标签资源完整、i18n 键完整性、JavaFX 线程规则。
- 设计器：字段控制网格、DDL 预览、ALTER 序列、视图保存和刷新。
- 对象生命周期：表重命名/清空/删除/克隆，视图重命名/删除/克隆。
- 数据：SQL/CSV/JSON/XML 导出，CSV/JSON/SQL 导入，dump、run SQL file、H2 间传输，过滤、分页、默认值、NULL/空串/VARBINARY、批量、中断和错误继续。
- 终端：基础命令注册与执行。

## 13. 验收标准

1. 可从连接引导新建和编辑 H2 连接（三种模式），并成功测试连接。
2. 文件模式可创建新库或打开已有库；未勾选创建时文件不存在直接报错。
3. 内存模式连接期间可正常操作，连接信息明确提示库生命周期。
4. 远程模式可构造正确 TCP/SSL URL 并连接。
5. 打开连接后能读取并展示数据库信息、表、视图、字段和行数。
6. SQL 查询可显示列、行、更新数量、耗时和错误；多语句事务行为符合设计。
7. 查询与终端入口均可工作，关闭后无 JDBC 资源泄漏。
8. 只读连接、文件丢失、非 H2 文件和 SQL 错误均有可理解提示。
9. MySQL、MariaDB、MongoDB、达梦、SQLite 入口和方言行为无回归。
10. 新增 H2 测试全部通过，相关 `fx-db` 与 EasyShell 测试通过。
11. 可加载并保存表、视图设计器，字段/约束不丢失，H2 函数能力边界有明确提示。
12. 可完成导入、导出、dump、SQL 文件执行和 H2 间传输，错误与资源关闭行为符合设计。
13. 表/视图数据可过滤、分页和编辑，NULL、空字符串、VARBINARY 和默认值行为符合 H2 语义。
14. 表/视图重命名、清空、删除和克隆动作可用，事件会刷新树和已打开数据页。
